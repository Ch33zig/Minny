# Minny

Eight months of web logs from a ten-person company, one planted insider breach, and a detector that gets attacked hundreds of ways to prove it would catch the next one.

## Start here

**Building tonight?** [docs/handoff/README.md](docs/handoff/README.md), the four-track build handoff: ownership, branches, checkpoints, and the shared contracts every track writes against. Read that file, then your own track file, then [the contracts](docs/handoff/00-CONTRACTS.md).

**Integrating a service?** [docs/technical-spec/00-START-HERE.md](docs/technical-spec/00-START-HERE.md), the larger-scope specification covering Composio, Elastic, Sentry, Gmail, and the shared JSON schemas. It is the integration reference, not the build plan; the handoff says which parts of it apply.

These documents describe a proposed build. Live integrations and deployment have not been implemented or verified, and no dataset is committed to this repository.
